Three steps to a working deck

  1. Click an empty slot to add a button, then name it and pick an icon.
  2. Give it an action — or chain several into a macro with delays between them.
  3. Choose Pair a device and scan the code. Changes reach it as you make them.

Sounds

Eight slots for Play a sound buttons. Replace any with your own WAV or MP3, up to 8 MB. Sounds play through this computer's speakers; tablets never download them.

OBS Studio

Only needed for OBS buttons. In OBS open Tools › WebSocket Server Settings, enable the server, then copy its address and password here.

Pair a device

Scan to pair

  1. 1Keep this computer and the tablet or phone on the same wifi network.
  2. 2Scan the code with the device's camera, then tap the link it offers.
  3. 3No camera? Open the address on the device and type the 6-digit code.

Only paired devices can press buttons. Each one gets its own key, and you can remove it below at any time.
